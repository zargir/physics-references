CachyOS → GitHub → Netlify Workflow

This is the workflow for updating the website stored in the site folder using the CachyOS terminal.

1. Open the website folder

cd ~/Desktop/site

This is the working directory containing files such as: 

site/
├── index.html
├── circuit.html
└── other files

2. Check what changed

git status

Git shows which files have been modified, added, or deleted.

3. Add changes to Git

git add .

This prepares all changed files for a commit.

4. Create a revision snapshot

git commit -m "Describe your changes"

Example: 

git commit -m "Added electricity chapter"

A commit is a saved version of the project.

5. Push the revision to GitHub

git push

Git sends the new revision to: 

https://github.com/zargir/physics-references

6. Netlify deployment

GitHub
   |
   | New commit
   ↓
Netlify
   |
   | Automatic deployment
   ↓
https://physics-references.netlify.app/

After GitHub receives the push, Netlify automatically updates the live website.

Complete update sequence

cd ~/Desktop/site

git status

git add .

git commit -m "Updated website"

git push

Working from another machine

First download the project: 

git clone git@github.com:zargir/physics-references.git

Then update normally: 

git pull

# edit files

git add .
git commit -m "New revision"
git push

End of workflow reference.
